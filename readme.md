# NovaPulse AI — SaaS Landing Page

NovaPulse is a modern, responsive SaaS landing page for an autonomous API observability and workflow tracing platform. Built as part of the **Sankar Group Front-End Development Internship Assignment**.

## 🛠️ Technologies Used
- **HTML5:** Clean, semantic structure with accessibility best practices (ARIA tags, labels).
- **Tailwind CSS (via CDN) & Custom CSS:** Responsive grid layouts, modern dark-mode palette, and micro-interactions.
- **Vanilla JavaScript (ES6+):** Lightweight, zero-dependency logic handling smooth scrolling, interactive modal state, live price toggling, mobile navigation drawer, and form validation.
- **FontAwesome & Plus Jakarta Sans:** Crisp iconography and typography.

---

## 📋 Features Implemented
1. **Interactive Navigation:** Sticky blur navbar, responsive mobile menu drawer, and smooth anchor scrolling.
2. **Hero Section:** Value proposition headline, live telemetry widget preview, and dual CTA buttons.
3. **Features Grid:** 6 structured cards showcasing platform capabilities with subtle glowing borders.
4. **How It Works:** 3-step progressive onboarding timeline with terminal snippets.
5. **Dynamic Pricing:** Interactive Monthly/Annual billing switch with instantaneous recalculation and badge discount state.
6. **Form Validation:** Client-side email and required field checking with loading indicators and success state.
7. **Action Modal:** Functional popup modal for registration and authentication.
