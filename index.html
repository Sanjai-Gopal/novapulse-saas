Connect Your Services via OpenTelemetry SDK

Export telemetry traces directly into your NovaPulse pipeline using standard libraries.

Node.js / Express
import { initNovaPulse } from '@novapulse/sdk';
initNovaPulse({ apiKey: process.env.NOVAPULSE_API_KEY, serviceName: 'checkout-service' });
Python / FastAPI
from novapulse import NovaPulseMiddleware
app.add_middleware(NovaPulseMiddleware, api_key=os.getenv("NOVAPULSE_API_KEY"))
cURL / Raw Telemetry POST
curl -X POST https://telemetry.novapulse.io/v1/traces -H "Authorization: Bearer np_live_..." -d '{"service":"edge-router"}'
